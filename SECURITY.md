# Security and privacy

This repository contains instructions and local installation/validation helpers. It does not need API credentials or real client data. Inspect a skill before installing it; its instructions can influence an assistant with access to your tools.

Keep client materials in an authorized private location outside the public repository. Git ignore rules are not a data-loss prevention boundary. Do not paste secrets into issues, pull requests, examples, prompts, or evaluation outputs.

For a security issue, use [private vulnerability reporting](https://github.com/afurm/ai-practitioner-toolkit/security/advisories/new), which is enabled for this repository. If it becomes unavailable, open a minimal issue asking for a private reporting channel without exploit details or sensitive data. For ordinary bugs, use an issue with a synthetic reproduction.

The current default branch is supported. Report the affected revision, a synthetic reproduction, expected versus observed behavior, and impact without client information or live credentials. This community project does not promise a response-time SLA or compliance certification. Disclosure and remediation timing will be agreed with the reporter.

The skill does not grant system permissions, validate legal compliance, or replace application-enforced authorization. Existing host, repository, and user instructions still apply. Recommendations and readiness reviews require evidence for the actual environment.
